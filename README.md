# เที่ยวน่าน: เว็บตัวอย่าง

เว็บตัวอย่างแนะนำที่เที่ยวจังหวัดน่าน 5 หน้า สำหรับแสดงผลงานออกแบบและพัฒนาเว็บไซต์

**ดูเว็บจริง:** https://teerapat063.github.io/nan-travel-guide/

## หน้าในเว็บ
- หน้าแรก
- ที่เที่ยว (6 แห่ง)
- แผนเที่ยว 3 วัน
- ข้อมูลการเดินทาง
- ติดต่อ

## จุดเด่น
- ใช้งานได้ทั้งมือถือและคอมพิวเตอร์
- ตั้งค่า SEO พื้นฐาน (Title, Meta description, H1)
- โครงสร้าง HTML/CSS ล้วน ไม่ต้องใช้เซิร์ฟเวอร์
- ไม่ใช้รูปภาพที่มีลิขสิทธิ์

## หมายเหตุ
เป็นเว็บตัวอย่าง ข้อมูลรวบรวมจากแหล่งท่องเที่ยวสาธารณะ ฟอร์มติดต่อและเบอร์โทรเป็นของสมมติ ไม่ใช่เว็บทางการของจังหวัดน่าน
